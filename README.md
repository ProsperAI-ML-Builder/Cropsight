# Cropsight.

An AI model that detects crop diseases from phone photos, built for Nigerian farmers.

## The problem
Many smallholder farmers in Nigeria cannot identify crop diseases early.
Extension officers are few and hard to reach, so harvests are often lost.

## What this project does
A farmer points their phone at a leaf and gets:
1. A check that the photo is actually a plant leaf
2. The crop identified (cassava, tomato, maize, rice, pepper)
3. A disease diagnosis, or "healthy"
4. A message saying "I'm not sure" when confidence is low

## Roadmap
- [ ] Phase 1: Cassava and tomato
- [ ] Phase 2: Maize, rice and pepper
- [ ] Phase 3: Yam and other crops using local field photos
- [ ] Offline mobile app

## Status

## Limitations
This tool is a first-alert aid, not a replacement for agricultural experts.
